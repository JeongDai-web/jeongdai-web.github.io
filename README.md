# 정다이 홈페이지

GitHub Pages에 그대로 올리면 열리는 연구자 홈페이지입니다.

## 들어 있는 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 홈페이지 내용 전체. 글자를 고칠 때는 이 파일만 보면 됩니다. |
| `style.css` | 색, 글씨체, 배치. 맨 위 몇 줄만 고치면 색과 글씨체가 바뀝니다. |
| `notes/sample.html` | 글 한 편의 틀. 새 글을 쓸 때 복사해서 씁니다. |
| `README.md` | 이 안내문. 홈페이지에는 보이지 않습니다. |

## GitHub에 올리기

1. github.com에 로그인하고 오른쪽 위 **+** → **New repository**를 누릅니다.
2. 저장소 이름을 `사용자이름.github.io`로 적고(사용자이름은 내 GitHub 아이디), **Public**을 고른 뒤 만듭니다.
3. 저장소 화면에서 **uploading an existing file**을 누르고, 압축을 푼 폴더 **안의 내용물**(`index.html`, `style.css`, `README.md`, `notes` 폴더)을 끌어다 놓습니다. 폴더째가 아니라 안의 것들을 올려야 합니다.
4. 아래 **Commit changes**를 누릅니다.
5. 몇 분 뒤 `https://사용자이름.github.io`로 접속합니다. 안 열리면 저장소의 **Settings → Pages**에서 Branch가 `main`으로 되어 있는지 확인합니다.

## 공개하기 전에 고칠 곳

`index.html`에서 대괄호 `[ ]`로 표시된 자리를 모두 채우거나 지웁니다. 파일 안에서 `[수정]`을 검색하면 고칠 자리가 차례로 나옵니다.

- [ ] 영문 이름
- [ ] 이메일 주소 (두 군데: 소개 옆, 맨 아래 연락처)
- [ ] 프로필 사진
- [ ] 2025~2026년 논문 세 편의 정확한 제목, 저자 정보
- [ ] 논문 원문 링크, Google Scholar · KCI · ORCID 주소
- [ ] 강의 학기, 학력
- [ ] 소개 문장과 연구 질문 네 가지 (초안이니 내 말투로 고치기)
- [ ] 글과 자료의 예시 카드 네 개 (실제 글로 바꾸거나 지우기)

## 내용 고치기

1. GitHub 저장소에서 `index.html`을 누릅니다.
2. 오른쪽 위 **연필 아이콘**을 누릅니다.
3. 글자를 고칩니다. `<` 와 `>` 사이의 기호는 건드리지 않고, 그 사이의 한글만 바꾸면 됩니다.
4. **Commit changes**를 누르면 몇 분 안에 홈페이지에 반영됩니다.

## 새 글 올리기

1. `notes/sample.html`을 열어 내용을 전부 복사합니다.
2. `notes` 폴더에서 **Add file → Create new file**을 누르고, 이름을 영어로 짓습니다. 예: `mtss-tiers.html`
3. 복사한 내용을 붙여 넣고 제목과 본문을 고친 뒤 저장합니다.
4. `index.html`의 "글과 자료" 부분에서 글 카드 덩어리 하나를 복사해 붙이고, 제목, 요약, 주제(`data-topic`), 파일 이름(`href="notes/mtss-tiers.html"`)을 바꿉니다.

## 사진 넣기

1. 정사각형에 가까운 사진을 `profile.jpg`라는 이름으로 `index.html`과 같은 곳에 올립니다.
2. `index.html`에서 `[프로필 사진]`이 있는 줄을 지우고, 바로 아래 줄의 `<!--` 와 `-->`를 지웁니다.

## 색과 글씨체 바꾸기

`style.css` 맨 위 `:root { ... }` 안의 값만 고칩니다.

- `--sky`: 버튼과 연락처 영역의 하늘색
- `--sky-pale`: 페이지 바탕색
- `--blue`: 링크와 작은 라벨의 파란색. 하늘색보다 짙어야 글자가 잘 읽힙니다.
- `--font-head`, `--font-body`: 제목과 본문 글씨체. 다른 글씨체를 쓰려면 `index.html`과 `notes` 안 파일들의 Google Fonts 주소도 함께 바꿔야 합니다.
